# task-001: Mandatory update enforcement decision

Status: backlog
Source: docs/product-roadmap.md (Next tasks #9, Release Requirements)

## Description

Defer mandatory update enforcement until a deliberate product decision is made.

## Acceptance criteria

- [ ] Treat newer releases as informational for now; do not block startup, navigation, or normal use.
- [ ] Do not label an available update as required in the current product experience.
- [ ] Define user-impact, rollout, recovery, and support requirements before enabling enforcement.
- [ ] Explicitly decide whether and when minimum-supported-version enforcement is needed.
- [ ] Specify behavior for offline startup, failed downloads, rollback, and recovery.
