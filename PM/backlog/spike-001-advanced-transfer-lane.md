# spike-001: Secure advanced transfer lane evaluation

Status: backlog
Source: docs/product-roadmap.md (Possible Future Lanes), docs/advanced-transfer-lane.md

## Description

Evaluate a secure advanced transfer lane (SFTP/FTPS, not plain FTP) for interoperability-focused
users, while keeping browser-based HTTP sharing as the basic-user experience.

## Notes
