NOTES:

- Firt off is a question about what browsers support. Is it possible to have a single "Browse" button support: single file select, multi file select, single folder select, multi folder select, and a combination?
- Along ths same lines, can the drag and drop support the above listed actions?
- The search element. This should be tied to Everything by Voidtools if possible. Only shearch folder and file names, not content.
- - When a search is entered a dropdown list is displayed. This should be in front of the rest of the UI so it does not move the rest of the elements. Clicking outside of the dropdown will close it.
- - When the search text input gains focus, all of the text is selected to make it easier to switch searches.
- The breadcrumbs. This should be similar to Windows 11 display of your currently open directory in relationship with the root shared folder. Let's not use the term root in the UI though. I think a simple ~/ would suffice. In this breadcrumbs display we show each directory with a forward slash between them. The folders displayed are, when hovered over, buttons. If not hovered, they appear like typical text. Clicking on a breadcrumb navigates to that folder.
- The file explorer view:
- - We only need to see the name, type (folder/file) and size columns. Folders do not have a size displayed. Always display the extension for files.
- - Right click opens a context menu with options to: Download, Rename, and Delete. (enable/disable state based on permissions)
- - This window is scrollable in both directions
- The permissions status always shows all four types: upload, download, rename, delete. Each permission type a user has been granted is visually more prominant that the ones they do not have.
