Reading guide
-------------
- Headings are plain text lines (no [ ]).
- Interactive controls are inside [ ]:
  - [ Path field ... ] = text field/path display
  - [ Change folder ] = button
  - [ Copy link icon ] = button
  - [ Open admin console ] = button
- The QR code is represented as a boxed area.
- Horizontal divider lines separate the three instructional steps.


Three-step flow (intended user journey)
---------------------------------------
1) Choose a shared folder
2) Share folder link
3) Grant access
